Earlier names
^^^^^^^^^^^^^

These names still work, as the classes they now stand for, with a
``DeprecationWarning``, and are not scheduled for removal:

- ``Lognormal``, now :class:`~HARK.distributions.LogNormal`;
- ``MeanOneLogNormal``, now :class:`~HARK.distributions.LogNormalMeanOne`;
- ``TruncatedLognormal`` and ``TruncatedLogNormal``, now
  :class:`~HARK.distributions.LogNormalTruncated`;
- ``MeanOneTruncatedLogNormal``, now
  :class:`~HARK.distributions.LogNormalTruncatedMeanOne`.
